# TracePilot 开发回归

从仓库根目录检查本轮差异，保留已有未提交改动。按修改位置选择测试，执行与证据口径见 [验证指南](references/validation.md)。已有任务授权适用于其范围内验证；本 Skill 不额外授予模型调用、镜像下载、部署或发布权限。

## 必须保持的行为

- 搜索、直接读取、隔离副本和编译都复用文件策略。拒绝路径后，不应启动编译或测试进程。
- 补丁预览仅允许生产 Java 源码；确认前正式源码保持不变。错误提案摘要、源码变动后的旧确认均须拒绝。
- 正式写入后测试失败应回滚本次修改；检查点恢复保留待确认状态，重复确认使用已有回执。结果未知时停止自动重试。
- 受限运行器不可用时停止；默认工作流不能回退到宿主机执行陌生代码。

## 报告要求

报告命令、环境、通过/失败/跳过数量及未覆盖范围；定位失败原因后再决定修复或补测。离线评测必须检查逐例字段，不能仅凭退出码宣布所有边界通过。

区分规则规划器、固定模型动作回放、真实 Docker 隔离断言和外部真实模型评测。只报告本轮实际运行的证据，不沿用其他工作区或历史报告的通过数字。测试中的恢复若仅重建服务对象，不改称进程崩溃恢复。
